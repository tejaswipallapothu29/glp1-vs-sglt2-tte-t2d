# GLP-1 vs. SGLT2 Inhibitors: A Target Trial Emulation
Causal comparison of GLP-1 vs. SGLT2 inhibitors for type 2 diabetes using target trial emulation, OMOP CDM, and fairness analysis.

Comparing GLP-1 receptor agonists and SGLT2 inhibitors as second-line
therapy in type 2 diabetes, benchmarked against the SUSTAIN 8 trial,
with subgroup fairness analysis.

**Note:** Uses Synthea synthetic data. This is a methods demonstration,
not a clinical finding.
